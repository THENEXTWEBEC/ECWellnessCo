# The Ecuadorian Wellness Company

Static bilingual website for GitHub Pages.

## Pages

- `/` — Spanish homepage
- `/en/` — English homepage
- `/privacidad.html` and `/en/privacy.html` — privacy information
- `/404.html` — not found page

Styles and interactions live in `styles.css` and `main.js`. The site has no build step or JavaScript dependencies. Responsive WebP photography is served from `assets/images/`; source links are recorded in `assets/images/SOURCES.md`. The Inter font is served from `assets/`.

## Publishing

GitHub Pages serves the repository root on the `main` branch with the custom domain in `CNAME`. Merge the redesign branch to publish it. Verify the domain, both language paths, metadata, and contact links after deployment.

## Content notes

The photographs are licensed illustrative images. They do not depict EC Wellness Co staff, confirmed properties, or a documented retreat. Dates, pricing, duration, inclusions, and exact locations need confirmation before publication on the site.

The structured data describes the business as an `Organization`. The repository does not establish that it operates as a medical provider or has a verified physical storefront, so `MedicalOrganization` and `LocalBusiness` would be inaccurate without more evidence.

The Inter font is distributed under the SIL Open Font License included in `assets/OFL-Inter.txt`.
